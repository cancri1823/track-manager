🗺️ 照片與軌跡路徑管理總系統 — 操作使用說明

四個子系統的完整程式碼已全部內嵌於此單一 HTML 檔案中，無論將此檔案放在電腦哪個資料夾，點擊上方分頁即可直接開啟使用，不會再出現「找不到檔案」的問題！

🚀 推薦最佳作業流程 (Workflow)

STEP 1 · 足跡提取
📍 Google 足跡轉檔

將手機/Google 匯出的 Timeline JSON 載入，依日期或交通方式篩選並修整偏離點，匯出成乾淨的 .gpx 或 .kml。

STEP 2 · 軌跡精修與分類
🗺️ 軌跡路徑管理

直接連接本機軌跡資料夾，進行多點切割、節點拖曳微調、多檔合併、加上登山/溫泉等 18 種自訂地標，並直接覆寫回硬碟原檔。

STEP 3 · 照片定位分群
📸 照片地圖相簿

批量匯入旅途照片，自動解析 EXIF 依「同日合併半徑」建立地圖相簿；無 GPS 的照片可直接在台灣通用電子地圖上拖曳紅針補齊座標。

STEP 4 · 遊記與花費總成
📓 旅遊地圖遊記

結合「多日軌跡 + 景點相簿 + 每日消費明細 (單價×數量)」，支援單日路線聚焦檢視，最後一鍵匯出可獨立分享的互動式遊記 HTML！

分頁 1：GPX / KML / KMZ / JSON 軌跡路徑管理系統

狀態：已完整內嵌 (無須外部檔案)

💡 核心特色：支援 File System Access API 直接讀寫電腦本機資料夾，修改檔名、顏色、節點或切割路線後，可直接覆寫回硬碟原檔，並自動維護 _tracks_metadata.json 索引。

標準操作步驟：

  1. 連接或匯入檔案：點擊左上角「📂 連接」選擇電腦中存放軌跡的資料夾（推薦，可直接同步硬碟），或點擊「📄 匯入」單次載入 .gpx, .kml, .kmz, .json。
  2. 智慧日期與分類篩選：系統會最優先從檔名解析 8 碼日期（如 20121201）與自動歸類（登山健行、台灣旅遊、出國旅遊、Google足跡等），點擊表格標題列可依檔名、分類、日期、距離/爬升排序。
  3. 進階節點編輯與復原：點選任一軌跡開啟右側浮動面板，點擊「✏️ 節點編輯」即可：
    • 移動節點：左鍵拖曳藍白圓點。
    • 新增節點：點擊兩點之間的「半透明小圓點」或直接點擊路線線條。
    • 刪除與復原：對節點按「滑鼠右鍵」刪除；隨時可按 Ctrl+Z 或「↩️ 復原」退回（最多 30 步）。
  4. 多點自由切割與多檔組合：點擊「✂️ 多點切割」在路線上點選多個切割點，確認後自動拆分為多個獨立 GPX 檔；在左側清單勾選多個檔案則可點擊「🧩 組合」合併為一檔。
  5. 自訂 18 種戶外地標圖示：點擊「+ 地圖點選新增」可在地圖標註三角點⛰️、登山口🥾、營地⛺、水源💧、溫泉♨️等 18 種圖示與自訂底色。

分頁 2：Google 足跡 Timeline 讀取 / 編輯 / 轉檔工具

狀態：已完整內嵌 (無須外部檔案)

💡 核心特色：專為處理 Google 時間軸匯出的月份/年度 .json 檔案設計，支援一次拖曳多個月份合併統計、交通工具色彩區分、地圖節點修正與整天批次勾選匯出。

標準操作步驟：

  1. 載入與合併多個 JSON：將 Google Takeout 或手機匯出的 Timeline JSON 拖曳至頂部虛線框（支援一次選取多個月份檔案自動依時間排序合併）。
  2. 檢視自動統計報表：系統自動計算「總筆數（移動/停留）」、「總里程」、「各交通方式（機車、汽車、單車、步行、火車等）次數與時數」以及「停留最久 Top 8 地點」。
  3. 按日期或類型篩選勾選：
    • 透過篩選列可只看「移動路線」或「停留點」、特定交通工具或特定日期。
    • 列表依日期分組，直接勾選日期標題列即可一鍵全選或取消當天的所有行程。
    • 可在列表內直接下拉修改誤判的交通工具類型，或直接修改停留點名稱。
  4. 地圖視覺化修整路徑：點擊列表右側的「✎」按鈕，即可在地圖上拖曳綠/紅/橘色節點修正漂移座標、點擊黃線新增節點，或雙擊中間節點刪除，完成後按「儲存修改」。
  5. 多種格式匯出：可自由勾選是否包含「停留點」與「移動路線」，並一鍵匯出為標準 GPX、KML、KMZ 或修改後的完整原格式 JSON。

分頁 3：照片地圖相簿管理系統

狀態：已完整內嵌 (無須外部檔案)

💡 核心特色：高速讀取照片 EXIF GPS 與拍攝日期，自動將「同一天且在指定半徑內」的照片聚合成精美地圖縮圖相簿，並提供「無座標照片地圖拖曳取點」功能。

標準操作步驟：

  1. 設定同日合併半徑並匯入照片：於頂部工具列選擇同日合併半徑（200公尺 / 500公尺 / 1公里 / 3公里），再點擊「匯入照片」批量選取照片（支援進度條顯示與自動縮圖壓縮）。
  2. 自動分流「地圖相簿」與「待定照片」：
    • 具備完整拍攝日期與 GPS 的照片，會自動在地圖上生成帶封面縮圖與張數徽章的相簿標記。
    • 缺少日期或 GPS 座標的照片（如相機拍攝或通訊軟體轉傳），會自動歸入左側「待定照片」分頁。
  3. 為待定照片補齊座標與歸屬：在「待定照片」點擊「設定座標 / 歸入相簿」，可選擇直接併入現有相簿，或點擊「切換至地圖拖曳紅色圖釘取得座標」，在地圖上點選位置建立新相簿。
  4. 編輯相簿標題、照片敘述與重設座標：點擊地圖相簿開啟檢視視窗，可修改地點名稱、日期、為每張照片加上敘述說明、將單張照片移至其他相簿，或點擊「重設相簿座標」微調位置。
  5. 本機持久化與 JSON 備份：所有資料皆自動儲存於瀏覽器 IndexedDB，並可隨時點擊右上角下載圖示匯出完整 .json 備份檔。
📓

分頁 4：旅遊地圖遊記製作與管理系統

狀態：已完整內嵌 (無須外部檔案)

💡 核心特色：支援多篇遊記總表管理，整合「獨立軌跡編輯 + 20種彩色分類圖釘 + 單日路線聚焦 + 消費統計報表 (單價×數量)」，並可匯出單一 HTML 互動式遊記網頁。

標準操作步驟：

  1. 建立遊記與批量拖曳匯入：在首頁總表點擊「+ 新建地圖遊記」設定名稱與起訖日期；進入編輯器後，可直接將 .gpx, .kml, .kmz 與照片拖曳進視窗批量匯入（具備重覆軌跡/照片智慧偵測機制）。
  2. 依日期分組管理與「只看當天」聚焦：左側浮動面板將地點與路徑依 Day 1 ~ Day N 分組，可拖曳調整順序，或點擊日期列上的「🎯 只看當天」按鈕，讓地圖只顯示該日的軌跡與景點。
  3. 手繪/切割軌跡與切斷長直線：支援地圖直接手繪新路徑、節點拖曳/插點/刪點/切割；若軌跡含跨日長直線跳躍，可點「⚡ 切斷長直線」自動分段；地圖上方可一鍵切換顯示 S(起點)/E(終點) 標記與「台灣通用電子地圖」。
  4. 記錄地點遊記、20 種圖示與消費明細：右側面板可設定地點所屬日期、更換 20 種圖釘圖示與顏色、撰寫遊記故事，並新增消費紀錄（支援單價 × 數量自動計算與 6 大類別統計）；點擊頂部「📊 花費報表」可檢視每日與分類交叉統計表。
  5. 匯出獨立互動遊記 HTML：完成後點擊右上角「匯出遊記 (.html)」，即可產出內含地圖、S/E 軌跡、相簿與花費明細的獨立網頁檔，方便保存或分享給旅伴。
