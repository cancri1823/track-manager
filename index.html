🗺️ 照片與軌跡路徑管理總系統 — 操作使用說明

三個子系統的完整程式碼已全部內嵌於此單一 HTML 檔案中，無論將此檔案放在電腦哪個資料夾，點擊上方分頁即可直接開啟使用，不會再出現「找不到檔案」的問題！

🚀 推薦最佳作業流程 (Workflow)

STEP 1 · 軌跡精修與分類
🗺️ 軌跡路徑管理

直接連接本機軌跡資料夾，進行多點切割、節點拖曳微調、多檔合併、加上登山/溫泉等 18 種自訂地標，並直接覆寫回硬碟原檔；Google 足跡 Timeline 的 .json 也可直接匯入此處。

STEP 2 · 照片定位分群
📸 照片地圖相簿

批量匯入旅途照片，自動解析 EXIF 並依「地點合併半徑」歸入地點相簿；缺日期或座標的待定照片可勾選批次定位，先暫存、再最後儲存，並可把日期與座標寫回照片檔。

STEP 3 · 遊記與花費總成
📓 旅遊地圖遊記

結合「多日軌跡 + 景點相簿 + 每日消費明細 (單價×數量)」，支援單日路線聚焦檢視與「暫存／儲存」，最後一鍵匯出可獨立分享的互動式遊記 HTML！

分頁 1：GPX / KML / KMZ / JSON 軌跡路徑管理系統

狀態：已完整內嵌 (無須外部檔案)

💡 核心特色：支援 File System Access API 直接讀寫電腦本機資料夾，修改檔名、顏色、節點或切割路線後，可直接覆寫回硬碟原檔，並自動維護 _tracks_metadata.json 索引。

標準操作步驟：

  1. 連接或匯入檔案：點擊左上角「📂 連接」選擇電腦中存放軌跡的資料夾（推薦，可直接同步硬碟），或點擊「📄 匯入」單次載入 .gpx, .kml, .kmz, .json。
  2. 智慧日期與分類篩選：系統會最優先從檔名解析 8 碼日期（如 20121201）與自動歸類（登山健行、台灣旅遊、出國旅遊、Google足跡等），點擊表格標題列可依檔名、分類、日期、距離/爬升排序。
  3. 進階節點編輯與復原：點選任一軌跡開啟右側浮動面板，點擊「✏️ 節點編輯」即可：
    • 移動節點：左鍵拖曳藍白圓點。
    • 新增節點：點擊兩點之間的「半透明小圓點」或直接點擊路線線條。
    • 刪除與復原：對節點按「滑鼠右鍵」刪除；隨時可按 Ctrl+Z 或「↩️ 復原」退回（最多 30 步）。
  4. 多點自由切割與多檔組合：點擊「✂️ 多點切割」在路線上點選多個切割點，確認後自動拆分為多個獨立 GPX 檔；在左側清單勾選多個檔案則可點擊「🧩 組合」合併為一檔。
  5. 自訂 18 種戶外地標圖示：點擊「+ 地圖點選新增」可在地圖標註三角點⛰️、登山口🥾、營地⛺、水源💧、溫泉♨️等 18 種圖示與自訂底色。

分頁 2：照片地圖相簿管理系統

狀態：已完整內嵌 (無須外部檔案)

💡 核心特色：讀取照片 EXIF 的 GPS 與拍攝日期，依「地點合併半徑」歸入地點相簿（同一地點可含不同日期的照片，並依日期分組排列）；待定照片可勾選批次處理，先暫存、再最後儲存，儲存後還能把拍攝日期與座標寫回照片檔。

標準操作步驟：

  1. 設定地點合併半徑並匯入照片：於頂部工具列選擇半徑（200公尺 / 500公尺 / 1公里 / 3公里），再點擊「匯入照片」批量選取照片。半徑內的照片（不分日期）會歸入同一個地點相簿。
  2. 自動分流「地點相簿」與「待定照片」：同時具備拍攝日期與 GPS 的照片自動歸入地點；缺少日期或座標者進入左側「待定照片」。
  3. 勾選待定照片，批次定位或納入地點：勾選多張照片後按「批次定位 / 歸入地點」，可輸入地點名稱與座標（或在地圖拖曳紅色圖釘取點），或選擇納入現有地點；也可統一設定拍攝日期。按下「暫存」只會記錄，照片仍留在待定區並標示暫存目的地，可個別或全部取消。
  4. 最後儲存：確認暫存區內容後按「最後儲存」，照片才正式歸入地點相簿。暫存內容會保留在瀏覽器中，重新開啟仍在。
  5. 寫入照片 EXIF：儲存後，按上方「寫入照片 EXIF」並選取原始照片（以檔名對應），即可把拍攝日期與座標寫入 JPEG 檔：可下載新檔 ZIP（不動原檔），或選擇資料夾直接覆寫原檔。
  6. 以表列檢視地點相簿：左側表列只顯示地點名稱、日期與張數，可展開看各日期；開啟地點後照片依日期分組（可切換新舊排序），並能修改單張日期、移至其他地點、重設地點座標。
  7. 本機持久化與 JSON 備份：資料自動儲存於瀏覽器 IndexedDB，並可隨時匯出完整 .json 備份檔。

分頁 3：旅遊地圖遊記製作與管理系統

狀態：已完整內嵌 (無須外部檔案)

💡 核心特色：支援多篇遊記總表管理，整合「獨立軌跡編輯 + 20種彩色分類圖釘 + 單日路線聚焦 + 消費統計報表 (單價×數量)」，並可匯出單一 HTML 互動式遊記網頁，並支援首頁總表「匯出全部備份 (.json) / 匯入備份 (.json)」完整打包所有遊記與相簿。編輯過程會自動「暫存」，按「儲存」才正式存入。

標準操作步驟：

  1. 建立遊記與批量拖曳匯入：在首頁總表點擊「+ 新建地圖遊記」設定名稱與起訖日期；進入編輯器後，可直接將 .gpx, .kml, .kmz 與照片拖曳進視窗批量匯入（具備重覆軌跡/照片智慧偵測機制）。
  2. 依日期分組管理與「只看當天」聚焦：左側浮動面板將地點與路徑依 Day 1 ~ Day N 分組，可拖曳調整順序，或點擊日期列上的「🎯 只看當天」按鈕，讓地圖只顯示該日的軌跡與景點。
  3. 手繪/切割軌跡與切斷長直線：支援地圖直接手繪新路徑、節點拖曳/插點/刪點/切割；若軌跡含跨日長直線跳躍，可點「⚡ 切斷長直線」自動分段；地圖上方可一鍵切換顯示 S(起點)/E(終點) 標記與「台灣通用電子地圖」。
  4. 記錄地點遊記、20 種圖示與消費明細：右側面板可設定地點所屬日期、更換 20 種圖釘圖示與顏色、撰寫遊記故事，並新增消費紀錄（支援單價 × 數量自動計算與 6 大類別統計）；點擊頂部「📊 花費報表」可檢視每日與分類交叉統計表。
  5. 暫存與儲存：編輯中的每項變更都會自動「暫存」；按頂部「儲存」才正式存入總表。返回總表時會詢問是否儲存，未儲存的遊記在總表標示「有暫存未儲存」，再次進入會還原暫存內容；「捨棄暫存」可回到上次儲存的版本。
  6. 匯出獨立互動遊記 HTML：完成後點擊右上角「匯出遊記 (.html)」，即可產出內含地圖、S/E 軌跡、相簿與花費明細的獨立網頁檔，方便保存或分享給旅伴。
